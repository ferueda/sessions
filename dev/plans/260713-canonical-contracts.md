# Harden canonical session and source contracts

## Goal

Complete M1 of the [V1 roadmap](260713-v1-implementation-roadmap.md) before
storage or provider adapters depend on the initial scaffold types. Sessions must
own printable identity, exact content hashing, canonical document invariants,
complete multi-input fingerprints, safe typed source failures, and one reusable
adapter conformance suite. These remain internal pre-1.0 contracts; this change
does not add persistent state, provider discovery, or CLI commands.

## Changes

1. `src/domain/session-identity.ts` — add a branded printable ID and codecs using
   the grammar `<kind>@<percent-encoded-instance-id>:<percent-encoded-native-id>`.
   Adapter kinds are open lowercase slugs, while instance/native IDs are
   non-empty, case-sensitive, well-formed Unicode and are never normalized.
   Formatting rejects programmer-invalid values; parsing returns a discriminated
   non-throwing result and accepts only canonical percent encoding. Add exact
   identity equality. Update the CLI and architecture identity wording with the
   grammar and round-trip behavior.

2. `src/domain/content-hash.ts`, `src/domain/session.ts` — replace the opaque
   segment hash string with `{ scheme: "sha256-utf8-v1", digest }` generated by
   one core helper over the exact UTF-8 bytes. Do not trim, normalize Unicode, or
   rewrite newlines. Reject ill-formed Unicode before hashing, recompute hashes at
   validation, and compare scheme, digest, and exact text so a collision cannot
   merge unequal content. Add a provider-neutral occurrence key identifying one
   segment by session, entry ordinal, and segment ordinal.

3. `src/domain/session-validation.ts` — add a pure, non-coercing runtime validator
   that returns either a `SessionDocument` or bounded safe issue codes/paths,
   never offending values. Require exact object shapes; valid identity and literal
   values; contiguous zero-based entry/segment ordinals in array order; existing
   non-self entry references; valid non-self, non-duplicate session relations;
   exact content hashes; and canonical UTC timestamps in
   `YYYY-MM-DDTHH:mm:ss.sssZ` form. Preserve missing optional values and unknown
   provenance; do not impose timestamp monotonicity or actor-to-origin inference.

4. `src/application/ports/session-source.ts`,
   `src/application/source-input-fingerprint.ts` — replace probe booleans with
   `ready | unavailable | unreadable`, add sanitized adapter-owned probe roots,
   and replace a candidate's single locator/fingerprint with at least one ordered
   `{ role, locator, fingerprint }` descriptor plus a versioned aggregate. A
   repository helper constructs candidates and hashes canonical JSON tuples of
   role, URI, nullable record ID, and input fingerprint; order, locator, role, or
   fingerprint changes must invalidate the aggregate. Adapter version and
   identity remain separate comparison fields.

5. `src/application/source-failure.ts`, `src/application/read-session-document.ts`
   — model unavailable, unreadable, malformed, source-changed, and unsupported-
   format failures as an erasable discriminated union carried by one error class.
   Generate messages centrally without adapter/raw text; retain a cause only in
   the error chain. The application read boundary verifies source/candidate kind,
   aggregate fingerprint, returned identity, and the full canonical document,
   then throws a bounded safe validation error rather than admitting invalid or
   partial data. Adapters must compare all input fingerprints before and after
   reading (or use an equivalent stable snapshot); a mismatch is
   `source-changed`.

6. `test/fixtures/session.ts`, `test/fixtures/synthetic-source.ts`,
   `test/contracts/session-source.contract.ts` — add deterministic factories and
   a factory-driven Vitest contract that future Cursor/Codex fixtures can invoke.
   Each test receives isolated state and awaited cleanup. Prove probes do not read
   transcript content or mutate state; discovery/read are deterministic regardless
   candidate order; every input participates in the aggregate; pre-read and
   during-read mutation reject without a document; missing metadata stays absent;
   unsupported evidence stays unknown; and all expected source failures are typed
   and safe. The synthetic source is test-only and uses a generic adapter kind.

7. Focused tests under `test/domain/` and `test/application/` — cover identity
   delimiters, percent encoding, Unicode and malformed input; published SHA-256
   vectors and exact-text distinctions; forged collision/hash mismatch behavior;
   validator shape/order/reference/timestamp/provenance failures; candidate
   aggregate ambiguity and ordering; candidate/document identity mismatch; and
   error-cause redaction. Use exact assertions, awaited rejections, and no shared
   mutable fixtures.

8. `docs/contributing/adapter-contract.md`, `docs/contributing/architecture.md`,
   `docs/contributing/testing.md`, `docs/architecture-memo.md`, and
   `docs/reference/cli-contract.md` — record the implemented internal contracts,
   strict timestamps/ordinals, multi-input read-race rule, hash ownership, exact
   printable ID, and conformance coverage while keeping adapters/indexing/queries
   labeled planned.

## Verify

- `pnpm exec vitest run test/domain test/application test/contracts`
- `pnpm deps:check`
- `pnpm check`

## Boundaries

- No concrete Cursor/Codex adapter, provider path probing, SQLite state, index
  service, query behavior, renderer, or new CLI command.
- No public plugin or package library API; `package.json#exports` remains empty.
- No copied Harness provider/cache abstractions, workflow analysis, automation
  filtering, or private fixtures.
