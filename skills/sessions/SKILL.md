# Sessions

Turn retained local agent sessions into a traceable answer. Preserve what the
evidence proves, what it does not prove, and how another person can reproduce the
result.

## Analyze

1. **Route.** Choose the one route that best matches the user's primary decision.

| User goal                                                            | Playbook                                                   |
| -------------------------------------------------------------------- | ---------------------------------------------------------- |
| Recover a decision, prior research, or transferable context          | [Search and context](references/search-and-context.md)     |
| Explain failure, drift, reversals, recovery, or unresolved work      | [Retrospective](references/retrospective.md)               |
| Find repeated working or communication preferences                   | [Preferences](references/preferences.md)                   |
| Audit whether a skill or workflow was eligible, used, and followed   | [Workflow audit](references/workflow-audit.md)             |
| Compare completion claims with recorded checks and later corrections | [Verification audit](references/verification-audit.md)     |
| Check what a parent, child, fork, or continuation transferred        | [Handoff continuity](references/handoff-continuity.md)     |
| Find recurring work or friction worth a reusable capability          | [Capability discovery](references/capability-discovery.md) |

Done when one primary outcome and playbook are selected. Add a second route
only when the first result leaves a required question unresolved.

2. **Load.** Read [the evidence protocol](references/evidence-protocol.md), then
   only the selected playbook.

   Done when both completion bars are available.

3. **Investigate.** Use the smallest useful `sessions` queries, then report facts,
   interpretation, limits, and the next action.

   Done when the question is answered with reproducible canonical evidence, or
   the exact missing evidence or authorization is named.
